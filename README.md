# StudyMate AI Agent

StudyMate AI Agent is a Python-based AI study assistant. It reads study notes from a `.txt` file, analyzes the text, generates a summary, creates quiz questions, identifies hard and easy concepts, and saves the result as a Markdown report.

## Planned Features

- Read study notes from a text file
- Analyze word count, sentence count, paragraph count, and keywords
- Generate a summary using Gemini API
- Generate quiz questions and answers using Gemini API
- Detect hard and easy concepts
- Save a final Markdown report

## Project Status

Step 1 has been completed. The project idea, system goal, agent workflow, planned tools, and programming concepts have been documented.

## Planned Usage

```bash
python src/main.py data/sample_notes.txt
```
