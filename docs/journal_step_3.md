## Project Title

StudyMate AI Agent

## Testing Process

Testing was performed during the implementation of the StudyMate AI Agent. The main purpose of testing was to make sure that the local tools, agent workflow, and report generation process work correctly.

The project uses `pytest` for automated testing. The tests are stored in the `tests/` folder.

The testing process focused on these parts:

1. File reading
2. Text analysis
3. Report generation
4. Agent workflow
5. Input validation
6. Error handling

The tests were not left until the end of the project. They were added while the main components were being implemented. This made it easier to find problems early and check that each part of the system worked before connecting it to the full agent workflow.
